# BENCH --- Workshop Organization

> **Build a better workspace.**

BENCH is a modern workshop organization storefront built around one
idea: when every tool has a place, the work becomes easier.

The concept focuses on practical storage, bench organization, tool
management, workshop furniture, and accessories for garages,
makerspaces, home workshops, and professional work areas.

------------------------------------------------------------------------

## 🔧 The BENCH Idea

BENCH is not designed as a generic hardware store.

The storefront treats the workshop as a system.

A good workspace needs:

-   A place for every tool
-   Fast access to frequently used equipment
-   Organized storage
-   Durable work surfaces
-   Clear visual zones
-   Flexible solutions that can grow with the workshop

The brand combines an **industrial workshop aesthetic** with clean
modern ecommerce design.

------------------------------------------------------------------------

## 🧱 Organize by Workspace

Instead of forcing visitors to browse only by product type, BENCH
organizes the experience around real workshop zones.

### THE BENCH

Work surfaces, benches, vises, mats, lighting and bench accessories.

### THE WALL

Pegboards, hooks, rails, tool panels and wall-mounted storage.

### THE DRAWER

Tool cabinets, drawer organizers, trays, dividers and small-parts
storage.

### THE FLOOR

Rolling cabinets, mobile carts, shelving and larger storage systems.

### THE FIELD KIT

Portable organizers, tool bags, cases and compact workshop essentials.

## 🧭 The Workshop System

A central BENCH experience can help visitors think about their workspace
as a collection of systems.

### 01 --- STORE

Where tools and equipment live.

### 02 --- SORT

Where small parts and accessories become easy to find.

### 03 --- BUILD

Where the main work happens.

### 04 --- MOVE

Where mobile carts and portable storage keep tools close.

### 05 --- IMPROVE

Where lighting, mats, organizers and accessories refine the workspace.

This gives BENCH a story beyond simply displaying products.

## 🚀 GitHub Pages

BENCH is structured for static GitHub Pages hosting.

After uploading the project:

1.  Open the repository.
2.  Go to **Settings**.
3.  Open **Pages**.
4.  Select the deployment source.
5.  Choose the main branch.
6.  Save.
7.  Wait for GitHub Pages to publish the site.

Relative paths and local assets are used so the project remains portable
between local development and GitHub Pages.
